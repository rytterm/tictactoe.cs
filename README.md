# winForms_TicTacToe
First project.


A simple player vs aitictactoe game usingc# and windows forms

Note: This version of the game is beatable due to the first move of the ai not being the best one.
To make it unbeatable you would need to make the ai do the best move even on the first move. 
However, this causes performance issues which is the reason this game is the way it is.
